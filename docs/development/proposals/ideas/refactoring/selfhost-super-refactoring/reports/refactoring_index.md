## 🎯 読む順序（推奨フロー）

### 1️⃣ まず読む（5分）
**[エグゼクティブサマリー](file:///tmp/refactoring_executive_summary.md)** ⭐⭐⭐
- **用途**: 計画全体の概要把握
- **内容**: 現状分析・目標・Phase概要・期待効果・ROI
- **読者**: 全員必読（意思決定者・実装者）
- **所要時間**: 5分

---

### 2️⃣ 実行時の手引き（実行中常時参照）
**[クイックリファレンス](file:///tmp/refactoring_quick_reference.md)** ⭐⭐⭐
- **用途**: 実行時のチートシート
- **内容**: Phase別チェックリスト・コマンド集・KPI確認方法
- **読者**: 実装者必携（作業中に常に参照）
- **所要時間**: 3分（最初に目を通す）

---

### 3️⃣ 詳細計画（Phase開始前に確認）
**[マスタープラン](file:///tmp/refactoring_master_plan.md)** ⭐⭐
- **用途**: Phase別の詳細タスク・手順・成果物
- **内容**: 各Phaseの詳細手順・推定工数・成功基準
- **読者**: 実装者・レビュアー
- **所要時間**: 15-20分（Phase開始前に該当箇所を読む）

---

### 4️⃣ リスク管理（問題発生時に確認）
**[リスク分析マトリックス](file:///tmp/refactoring_risk_matrix.md)** ⭐⭐
- **用途**: リスク軽減策・緊急時対応
- **内容**: リスク一覧・軽減策・緊急時フロー
- **読者**: 実装者・トラブルシューティング担当
- **所要時間**: 10分（問題発生時に該当箇所を読む）

---

### 5️⃣ 時間管理（スケジュール確認時）
**[ガントチャート](file:///tmp/refactoring_gantt_chart.md)** ⭐
- **用途**: 時間配分・進捗管理
- **内容**: Phase別タイムライン・並列実行オプション
- **読者**: プロジェクトマネージャー・実装者
- **所要時間**: 5分（スケジュール確認時）

## 📋 シーン別ガイド

### 🚀 これから開始する場合
```
1. エグゼクティブサマリー（5分）
   → 計画全体を理解
2. クイックリファレンス（3分）
   → Phase 0のチェックリスト確認
3. マスタープラン - Phase 0セクション（5分）
   → 詳細手順確認
4. 実行開始！
```

### 💻 Phase実行中の場合
```
1. クイックリファレンス
   → 該当Phaseのチェックリスト確認
2. マスタープラン - 該当Phaseセクション
   → 詳細手順・成功基準確認
3. （必要に応じて）リスク分析マトリックス
   → 問題発生時の対応確認
```

### 🐛 問題発生時の場合
```
1. リスク分析マトリックス
   → 該当リスクの軽減策確認
2. クイックリファレンス
   → 緊急コマンド確認
3. マスタープラン
   → 正常フロー再確認
```

### 📊 進捗報告の場合
```
1. ガントチャート
   → 進捗状況可視化
2. エグゼクティブサマリー
   → KPI達成状況確認
3. クイックリファレンス
   → 各Phase完了確認
```

```bash

```

### Step 2: 実行準備（3分）
```bash
# クイックリファレンスを読む
cat /tmp/refactoring_quick_reference.md | less

# Phase 0チェックリスト確認
grep "Phase 0" /tmp/refactoring_quick_reference.md
```

### Step 3: Phase 0開始（2時間）
```bash
# ベースラインテスト実行
tools/smokes/v2/run.sh --profile quick --filter "selfhost_*" \
  | tee /tmp/baseline_test_results.txt

# ブランチ作成
git checkout -b refactor/selfhost-super-cleanup

# 依存関係マップ作成
find apps/selfhost-compiler -name "*.hako" -exec grep -H "using\|new " {} \; \
  > /tmp/dependency_map.txt

# 重複ファイル差分確認
for f in $(find apps/selfhost-compiler -name "*.nyash"); do
  base="${f%.nyash}"
  [ -f "${base}.hako" ] && diff -u "$f" "${base}.hako" > "/tmp/diff_${f//\//_}.txt"
done

echo "✅ Phase 0完了！Phase 1へ"
```
