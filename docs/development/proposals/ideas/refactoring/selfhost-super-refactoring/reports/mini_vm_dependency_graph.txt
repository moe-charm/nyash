## 問題点: 循環依存

❌ **上位層への依存が存在**:
- common/mini_vm_binop.hako → vm/boxes/json_cur.hako
- common/mini_vm_compare.hako → vm/scan (存在不明)

✅ **推奨される依存方向**:
Layer 4 → Layer 3 → Layer 2 → Layer 1
(下位層のみに依存)

## 共通機能の重複

以下の関数が複数の箱で実装されています:

### _str_to_int() - 5箇所で重複
1. arithmetic.hako (115-130行)
2. op_handlers.hako (18-33行)
3. json_frag.hako (12行)
4. json_scan.hako (8行)
5. step_runner.hako (8行)

### _int_to_str() - 3箇所で重複
1. mir_vm_min.hako (30-36行)
2. mini_vm_scan.hako (112-123行)
3. arithmetic.hako (含まれる)

### index_of_from() - 5箇所で重複
1. mini_vm_scan.hako (4-19行)
2. json_frag.hako (10行)
3. flow_runner.hako (7行)
4. mir_vm_min.hako (41行)
5. step_runner.hako (6行)

### read_digits() - 4箇所で重複
1. mini_vm_scan.hako (126-144行)
2. json_frag.hako (11行)
3. json_cur.hako (36-59行) as read_digits_from
4. flow_runner.hako (8行)
