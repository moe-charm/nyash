- Glob: ファイル検索
- Read: ファイル内容読み込み
- Bash: コマンド実行（wc, grep, find等）

### 調査範囲
```bash
# 調査対象
apps/selfhost/vm/              # VM本体（32ファイル）

# 除外
apps/selfhost/parser/          # パーサー（別調査対象）
```
