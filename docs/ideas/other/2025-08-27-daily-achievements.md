## 📊 技術的ブレークスルー

### ガード構文の進化
```nyash
// 従来案: 特殊構文が必要
with table.lock as m { m.put(k, v) }

// Sync<T>案: 普通のメソッド呼び出し！  
table.put(k, v)
```

### 効果注釈の活用
- `@effect(read)` → 自動で共有ロック
- `@effect(write)` → 自動で排他ロック
- 新しい仕組み不要、既存システムを活用
