## 🔄 論文の移動手順

1. `papers-wip/` または `papers-under-review/` から完成版をコピー
2. このフォルダに配置
3. `git add` でGit管理に追加
4. コミットメッセージ例: `feat(papers): publish "Box-Oriented JIT" paper`

## 📝 ファイル形式

- PDF版: `paper-name.pdf`
- LaTeXソース: `paper-name/` フォルダ
- 補足資料: `paper-name-supplementary/` フォルダ
