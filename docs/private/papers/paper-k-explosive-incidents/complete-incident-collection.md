- **日付**: 2025年9月15日
- **症状**: CPU 99.9%で4分間暴走（PID: 531065, 531206）

- **対策議論**: 根治 vs PyVM回避 vs JSON v0バイパス
- **結論**: 根治が最善（回避策は技術的負債）
