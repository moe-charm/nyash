## 特徴的な記録方法

### 開発日記形式
```
Day 23 - AIパーサー事件
10:00 - HTTPプラグインが動かない
11:30 - ChatGPT「プラグインが悪い」
14:00 - にゃー「パーサーじゃない？」
16:00 - 真相判明：参照コピーのバグ
反省：AIを信じすぎてはいけない
```

### 決定の重要度マーク
- ⭐⭐⭐ 革命的（言語の根幹）
- ⭐⭐ 重要（大きな影響）
- ⭐ 通常（日常的決定）
