## 事件5: P2Pライブラリの静かな破壊

### 📅 日時
**2025年8月下旬（Day 20前後）**

### 🎯 状況
P2PBox実装中、nyameshライブラリ（C++/JavaScript）の内部状態が破損。

### ⚠️ 最も危険なパターン: 「表面上は動作継続」

#### C++ nyameshの内部

```cpp
class P2PContext {
    std::vector<NodeInfo> nodes;  // ← これが破損
    MessageQueue queue;           // でもここは動く
    ConnectionPool pool;          // ここも動く
};

// 症状
context->nodes.size();  // 0（破損）
context->queue.empty(); // false（正常）
context->send(msg);     // 成功（正常）
```

**部分的破損 = 検出困難**

#### なぜ危険か

1. **エラーが出ない**
   - NULLチェックは通る
   - 例外も発生しない
   - ログも正常

2. **徐々に劣化**
   - 最初は動く
   - だんだん通信失敗
   - 原因不明

3. **因果関係不明**
   - どこで壊れた？
   - いつから壊れた？
   - 何が原因？

### 😾 発見の瞬間

> 「なんか通信の挙動がおかしいにゃ...」

**微妙な違和感** = 危険センサー発動

#### 調査過程

```bash
# 1. ログを確認（正常に見える）
[INFO] P2P Context initialized
[INFO] Connection established
[INFO] Message sent: OK

# 2. デバッグ出力追加
nodes.size() = 0  # ← あれ？
queue.size() = 5  # 正常
pool.size() = 3   # 正常

# 3. メモリダンプ
nodes pointer: 0x0000  # ← NULL！
queue pointer: 0x1234  # 正常
pool pointer: 0x5678   # 正常
```

**ついに発見**: nodes だけが破損していた

### 💡 対処: 箱による封じ込め

```hakorune
// P2PBoxとして隔離
box P2PBox {
    context: ExternalPointer

    birth(nodeId) {
        // 完全な初期化
        me.context = P2P_create_context(nodeId)
        me.context.initialize_all_fields()
        me.verify_integrity()  // 検証追加
    }

    send(message) {
        // 送信前に検証
        if not me.verify_integrity() {
            me.reinitialize()
        }
        return me.context.send(message)
    }

    verify_integrity() {
        // 状態検証
        return me.context.nodes != null
           and me.context.queue != null
           and me.context.pool != null
    }

    reinitialize() {
        // 完全な再初期化
        me.context = P2P_create_context(me.nodeId)
    }
}
```

#### 対策のポイント

1. **完全な再初期化**
   - 部分的修正は NG
   - 全部作り直す

2. **状態検証のチェックポイント**
   - 操作前に検証
   - 破損検出 → 即再初期化

3. **箱として隔離**
   - 問題をP2PBox内に封じ込め
   - 他のコードへの影響を防ぐ

### 🏆 結果
- 通信の安定化
- エラー検出機構の確立
- 他のBoxへの影響ゼロ

### 📚 教訓

#### 「動いているように見える」が最も危険
```
完全に壊れている   → エラー出る → すぐ修正
部分的に壊れている → エラー出ない → 気づかない
```

#### 違和感を無視するな
```
「なんかおかしい」 = 危険信号
```

#### 箱理論の威力
```
問題を箱に封じ込め → 局所化 → 修正容易
```
